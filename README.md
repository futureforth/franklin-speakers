# FranklinSpeakers.com

Static site — no build step.

## Deploy on GitHub Pages
1. Push this folder's contents to the repo root.
2. Settings → Pages → Deploy from branch → `main` / root.
3. `CNAME` sets the custom domain to franklinspeakers.com. Point DNS at GitHub Pages.

## Files
- `index.html` — page + SEO meta + structured data
- `styles.css` — all styles (mobile-first)
- `assets/speakers/` — headshots (replace with high-res originals, keep filenames)
- `robots.txt`, `sitemap.xml`, `favicon.svg`
